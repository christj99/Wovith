# Wovith

Stage 0 implements the smallest Wovith runtime: synthetic sources, AST-first canonical DSL, validation, evaluation, built-in renderers, provenance, a Why panel, and local persistence.

## Commands

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm test
corepack pnpm build
```
